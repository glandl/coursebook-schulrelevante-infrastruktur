                  Sources

                  Primary sources (official documentation). The links were not checked individually in October 2026 (untested); content may change.

                  Virtualization

                  • VirtualBox: User Manual (chapters Virtual Networking, Snapshots, Cloning)
                  • Ubuntu: Ubuntu Server documentation and installation tutorial
                  • UTM (macOS): docs.getutm.app
                  • Proxmox VE: pve.proxmox.com/pve-docs
                  • Microsoft Hyper-V: Microsoft Learn: Hyper-V on Windows

                  Containers

                  • Docker: Docker Docs (in particular Install Docker Engine on Ubuntu, Volumes, Compose file reference, Docker security)
                  • Docker Compose: docs.docker.com/compose
                  • Open Container Initiative: opencontainers.org
                  • Podman: podman.io
                  • Nextcloud: Admin manual and official Docker image
                  • Linux kernel: Namespaces (man7.org), cgroups (man7.org)

                  Security and data protection

                  • General Data Protection Regulation (EUR-Lex)
                  • Austrian Data Protection Authority
                  • Federal Ministry of Education (BMB), information on data protection and IT at schools
                  • BSI IT-Grundschutz (Germany), for comparison
                  • CIS Docker Benchmark, hardening Docker (registration required)

                  Documentation

                  • GitHub Docs, GitHub Flavored Markdown Spec
                  • Markdown Guide: Cheat Sheet
                  • Pro Git
                  • Mermaid documentation
                  • Michael Nygard: Documenting Architecture Decisions

                  Notes on the sources

                  Only official documentation and legal texts were used. Statements about software versions, menu items and commands must be checked before the course (see the “untested” note in the Lab).
