Chapter 5

Documentation techniques

This chapter is the continuous script on documentation. It follows the order of the sessions, so each technique builds on the previous one. The session chapters only refer here: this is where how to document is explained, while the sessions say what to document.

All submissions go into the portfolio repository (private, pull requests) and are assessed with the assessment rubric.

  • Markdown, Git and pull request workflow
  • Network diagrams and IP plans
  • VLAN and permission matrices
  • Runbooks
  • Change logs for device policies
  • Processing register (GDPR) and ADRs {class=“pages pages-tree”}
