Portfolio submissions (documentation tasks and homework) are assessed on four criteria:

| Criterion | Description |
|---|---|
| Technical correctness | The implementation works and matches the task. |
| Completeness | All required parts are present. |
| Documentation quality | Clear, well structured, appropriate documentation technique. |
| School-context reflection | Data protection and security aspects are considered. |

_Weighting and scoring scheme to follow._
