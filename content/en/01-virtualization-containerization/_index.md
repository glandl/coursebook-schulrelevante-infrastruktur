Schools run a few servers for many tasks: learning platform, file storage, directory service, print server, administration software. In the past every task got its own computer, today they run on **virtual machines** or in **containers**. This saves hardware and electricity, makes backups and updates plannable, and allows changes to be tried out safely.

In this session you learn how virtualization and containerization work, when to use which technique, and how to build a Linux VM and a Docker service in a laptop lab. Everything runs on your laptop with free software.
