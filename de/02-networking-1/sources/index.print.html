Quellen

Primärquellen (Standards und offizielle Dokumentationen). Alle Links wurden im Oktober 2026 nicht einzeln geprüft (ungeprüft); Inhalte können sich ändern.

Grundlagen und Protokolle

  • IETF: RFC 1918, Address Allocation for Private Internets
  • IETF: RFC 3927, Dynamic Configuration of IPv4 Link-Local Addresses
  • IETF: RFC 2131, Dynamic Host Configuration Protocol
  • IETF: RFC 826, Address Resolution Protocol
  • IETF: RFC 1035, Domain Names: Implementation and Specification
  • IETF: RFC 4632, Classless Inter-domain Routing (CIDR)
  • IETF: RFC 4291, IP Version 6 Addressing Architecture

Verkabelung und Ethernet

  • IEEE 802.3 (Ethernet, inklusive Power over Ethernet): IEEE 802.3 Working Group
  • Strukturierte Verkabelung: ISO/IEC 11801 und EN 50173 (Normen, kostenpflichtig; Überblick in den Herstellerinformationen)

WLAN

  • IEEE 802.11: IEEE 802.11 Working Group
  • Wi-Fi Alliance: wi-fi.org (Wi-Fi 6/6E/7, WPA3)
  • EU: Durchführungsbeschluss (EU) 2021/1067 zur Nutzung des Frequenzbands 5945–6425 MHz (6 GHz) für WLAN, über EUR-Lex

Werkzeuge

  • Linux: ip(8), ss(8), resolv.conf(5)
  • Debian: Debian-Referenz, Kapitel Netzwerkkonfiguration und interfaces(5)
  • VirtualBox: Benutzerhandbuch, Kapitel Virtual Networking
  • libvirt: NAT-Netz „default“ und Brücken
  • UTM: Netzwerkmodi
  • Hyper-V: Virtuelle Switches
  • Cisco Packet Tracer (Netzwerksimulator): Cisco Networking Academy (Download und Kurs Getting Started with Cisco Packet Tracer)

Sicherheit und Datenschutz

  • BSI IT-Grundschutz-Kompendium: Bausteine zu Netzen und WLAN (z. B. NET.2.1 WLAN-Betrieb), bsi.bund.de, zum Vergleich
  • Datenschutz-Grundverordnung (EUR-Lex)
  • Datenschutzbehörde Österreich
  • Bundesministerium für Bildung (BMB)

Dokumentation

  • Mermaid Dokumentation (Flowchart, Sequenzdiagramm)
