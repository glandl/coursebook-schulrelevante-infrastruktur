Sicherheit und Datenschutz

Keine Rechtsberatung

Dieser Abschnitt gibt eine technische Orientierung. Rechtliche Fragen (z. B. Rechtsgrundlage, Speicherdauer, Auftragsverarbeitung) klärt die Schule mit der Datenschutzbeauftragten bzw. dem Datenschutzbeauftragten und dem Schulerhalter.

Das Wichtigste in Kürze

ThemaMaßnahme
Wenige AdministratorkontenFür die tägliche Arbeit ein normales Konto, für die Administration ein eigenes Administratorkonto. Der Domänen-Administrator wird nur für Domänenaufgaben verwendet.
Ein Dienst, ein ServerJede Rolle auf einem eigenen Server oder Container: Ein Fehler oder Angriff auf den Webserver erreicht nicht gleich den Domänencontroller. Genau so ist das Labor aufgebaut.
Nur nötige DiensteWas nicht gebraucht wird, wird nicht installiert. Server Core und minimale Debian-Installationen haben weniger Angriffsfläche.
UpdatesServer regelmäßig aktualisieren, auch im Labor. Debian: unattended-upgrades für Sicherheitsupdates. Windows: Windows Update.
FernzugriffRemotedesktop und SSH nie direkt aus dem Internet. SSH mit Schlüsseln, Remotedesktop mit NLA, von außen nur über VPN mit Mehrfaktor-Anmeldung.
Offene Resolver und DHCPDNS beantwortet rekursive Anfragen nur aus dem eigenen Netz. Nur ein geplanter DHCP-Server pro Netz, fremde DHCP-Server werden am Switch blockiert (DHCP Snooping).
VerschlüsselungWebseiten nur mit HTTPS. Interne Zertifikate aus einer eigenen Zertifizierungsstelle statt Browserwarnungen wegklicken. SMB1 bleibt abgeschaltet.
SicherungDomänencontroller, Freigaben und Konfigurationsdateien werden gesichert, und die Wiederherstellung wird geübt. Ein Snapshot ist keine Sicherung.

Datenschutz im Schulkontext

  • Verzeichnisdienst: Er enthält Namen, Klassenzugehörigkeit, Anmeldezeiten und Gruppen Minderjähriger. Das gehört in das Verzeichnis der Verarbeitungstätigkeiten (siehe Dokumentationsskript).
  • Protokolle: DHCP (welches Gerät wann im Netz), DNS (welche Seiten aufgerufen werden), Druckserver (wer was druckt) und Fernzugriff (wer sich wann anmeldet) erzeugen personenbezogene Protokolle. Festlegen, wer sie sehen darf und wann sie gelöscht werden.
  • Eigener Server oder Cloud: Bei Rollen in der Cloud (Entra ID, Universal Print, Autopilot) liegen die Daten bei einem Anbieter. Das braucht einen Auftragsverarbeitungsvertrag und eine Prüfung, wo die Daten verarbeitet werden. Bei eigenen Servern trägt die Schule die Verantwortung für Betrieb und Sicherheit selbst.
  • Abbilder (Team 7): Ein Festplattenabbild kann Daten der letzten Person enthalten, die den Referenzrechner benutzt hat. Referenzrechner nie mit echten Konten verwenden. Alte Festplatten vor der Weitergabe sicher löschen.
  • Testdaten: Im Labor nur erfundene Namen (lehrer01, schueler01). Keine echten Klassenlisten.
